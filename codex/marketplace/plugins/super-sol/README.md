# Super SOL for Codex

**넣기만 하면 자동으로 동작하는** Codex 품질 하네스입니다. ChatGPT와 Codex가 합쳐지면서 "무엇을, 어떻게 시켜야 하는지" 어려워하는 분들을 위해, 복잡한 설정 없이 평소처럼 요청하면 플러그인이 알아서 품질을 챙깁니다.

## 무엇을 하나

- 요청을 **자동 분류**해서(단순/일반/신중), 필요한 절차만 조용히 주입합니다.
- 코드를 바꾸면 **테스트/실행으로 확인**하도록 유도하고, 확인 없이 "완료"라고 하면 **한 번 더 작업**하게 만듭니다(무한 반복 방지: 최대 1회).
- 디버깅·렌더 작업처럼 신호가 분명한 경우에만 조사·검증 절차를 덧붙입니다.
- 초보자용 표현만 보여줍니다: `작업 분류 중`, `검증 확인`, `진행 상황 확인`.

## 무엇을 하지 않나 (안심 포인트)

- 추가 API를 **호출하지 않습니다**. 과금 없음.
- `OPENAI_API_KEY`를 **읽거나 요구하지 않습니다**.
- 모델을 **몰래 바꾸지 않습니다**. 서브에이전트를 **자동 생성하지 않습니다**.
- 현재 열려 있는 Codex 세션과 **구독 범위 안에서만** 동작합니다.
- 일상 대화·단순 질문에는 **개입하지 않습니다**.

## 설치

```bash
# 로컬 마켓플레이스 추가 후 설치 (Codex 안에서)
codex plugin marketplace add ./codex/marketplace
codex plugin install super-sol@super-sol-local
```

설치 후 훅 신뢰를 **한 번** 승인하면 끝입니다. 이후에는 그냥 평소처럼 작업하세요.

설치 전에 로컬에서 동작을 확인하고 싶으면:

```bash
bash codex/marketplace/plugins/super-sol/scripts/setup.sh
```

## 두 개의 층 (base vs benchmark)

| 층 | 내용 | 비용 |
| --- | --- | --- |
| **기본 플러그인** | 자동 품질 하네스(이 문서). Docker·API 키 불필요 | 무료·자동 |
| **벤치마크 도구** | `super-sol-eval`(저장소 루트) — 절차 효과를 통제 실험으로 측정 | dry-run 무료 / live는 명시적 동의 없이는 실행 안 됨 |

기본 플러그인은 모델 능력을 "높이는" 게 아니라, 누락·성급한 완료·검증 없는 답변을 줄여 **실제 산출 품질**을 모델의 천장 가까이 끌어올립니다. 절차가 정말 효과가 있는지는 저장소의 벤치마크 하네스로 따로 측정합니다.

## 동작 방식 (요약)

1. `UserPromptSubmit` — 요청을 분류하고 이번 턴의 증거 추적을 초기화한 뒤, 최소 규칙(실행성·검증)과 필요한 팩만 주입.
2. `PostToolUse` — 파일 변경/테스트 실행을 **관찰**해 증거로 기록(모델 주장이 아니라 실제 실행 결과).
3. `Stop` — 코드를 바꿨는데 검증이 없으면 한 번 더 확인하도록 요청(최대 1회), 그 외에는 통과.

모든 훅은 오프라인·fail-open입니다. 훅이 실패해도 Codex 작업은 멈추지 않습니다.
