# Super SOL — 최소 운영 규칙 (always-on)

이 블록은 Super SOL 플러그인이 항상 적용하는 최소 규칙입니다. 무겁게 만들지 않는 것이 목적입니다 — 측정으로 값어치가 확인된 두 가지만 담습니다.

- **실행성(Run what you change):** 코드를 바꾸면 실제로 돌려봅니다. 관련 테스트나 명령을 실행해 동작을 확인하세요.
- **검증 후 완료(Verify before done):** 확인 없이 "완료"라고 말하지 않습니다. 방금 바꾼 코드에 대한 테스트/실행 결과가 있어야 마무리합니다.

나머지 절차(디버깅 조사, 렌더 산출물 검증)는 작업 신호가 있을 때만 플러그인이 자동으로 주입합니다. 평소 대화나 단순 질문에는 개입하지 않습니다.

이 플러그인은 추가 API를 호출하지 않고, API 키를 읽지 않으며, 모델을 몰래 바꾸지 않습니다. 현재 Codex 세션과 구독 범위 안에서만 동작합니다.
